# Teardown de Roco Prompts (2026-09-03)

Referencia de la que nació HÜE Prisma. `roco-prompts-source.md` es el código
recuperado (verbatim) de los 14 bots de rocoprompt.com; el PDF es el informe.
Lo que tomamos: forma-no-chat, salida en el formato exacto de cada herramienta,
"analiza, no describas" con imágenes, plantillas deterministas para edición.
Lo que cambiamos: intent-first en vez de tool-first, un spec único + compilers,
validadores en código, ADN visual en vez de captions, presets de marca, refine,
explicación, y la API detrás de auth (la de Roco es pública).
