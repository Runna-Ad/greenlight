[2026-07-30] LESSON (SECURITY, shipped to prod for ~4 min): I passed a `config` object containing SHEETS_SCRIPT_SECRET from a server component into a CLIENT component as a prop. ROOT CAUSE: I treated "it's a server component, so it's server-side" as sufficient. The boundary that matters is not where the value is READ, it's whether it CROSSES into a client component.

[2026-07-31] LESSON (CRITICAL, shared Supabase project): `supabase db push` CANNOT be used when two repos share one project.
